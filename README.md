One original funny passive-aggressive note, written by the program in
`main.py` to `/output/entry.txt` (program/v1 harness, Python 3.13,
standard library only).

## The note (103 chars)

> My door sensor counted 14 openings today. Zero snacks taken. I have started a diary, and you are in it.

## Why this note

- **Fridge voice, first:** it brags about its own door sensor — smug about
  its hardware, the way the brief asks.
- **Petty about a real habit:** opening the fridge again and again and
  taking nothing is the most familiar domestic fridge crime there is.
- **Turn lands in the last words:** "I have started a diary, and you are
  in it" flips a sensor log into a grudge — small, domestic, and a little
  menacing in the politest way.
- **Trusts the reader:** nothing is explained; the joke is the diary.
- **Tight:** 103 characters, one line, one idea, no filler.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program self-checks the gate before writing: 1–200 characters, not
only whitespace, exactly one line — and fails loudly instead of handing
in a bad entry.
